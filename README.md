# ملوك الطرنيب — حزمة النشر

هذه الحزمة هي النسخة **المبنية** من الموقع، جاهزة للرفع إلى Render (خطة مجانية) ليصير للموقع رابط عام. لا تحتوي الشيفرة المصدرية الكاملة؛ المصدر في مشروع `molook-al-tarneeb.zip`.

> **مهم:** اجعل مستودع GitHub **خاصًا (Private)**. المشروع مرخّص رخصة خاصة (`LICENSE`) تمنع نشر الشيفرة وإعادة توزيعها دون إذن صاحبه. المستودع العام يعرض الملفات لكل الناس.

## ما في هذا المجلد

| الملف | وظيفته |
|---|---|
| `dist/` | الموقع والخادم المبنيان |
| `Dockerfile` | يشغّل `dist/server/index.js` على Node 22 (بلا تثبيت حزم) |
| `render.yaml` | يعرّف الخدمة لـ Render: الخطة المجانية، فحص الصحة `/healthz`، إعدادات الحدود |
| `LICENSE`، `OWNERSHIP.md` | الرخصة وتوثيق الملكية |

## الخطوات (نحو 15 دقيقة)

### 1) مستودع GitHub خاص

1. ادخل إلى [github.com](https://github.com) وسجّل حسابًا إن لم يكن لديك.
2. من زر **+** أعلى الصفحة اختر **New repository**.
3. الاسم: `molook-al-tarneeb`. اختر **Private**. اضغط **Create repository**.
4. في صفحة المستودع الجديد اضغط الرابط **uploading an existing file**.
5. افتح هذا المجلد على جهازك، حدّد **كل ما بداخله** (المجلد `dist` والملفات `Dockerfile` و`render.yaml` و`LICENSE` و`OWNERSHIP.md` و`README.md`) واسحبه إلى صفحة GitHub. استخدم متصفح Chrome أو Edge لأن سحب المجلدات لا يعمل في بعض المتصفحات.
6. انتظر انتهاء الرفع ثم اضغط **Commit changes**.
7. تأكد أن المستودع يعرض المجلد `dist` والملف `Dockerfile` في أعلى مستواه (لا داخل مجلد إضافي).

### 2) Render

1. ادخل إلى [render.com](https://render.com) وسجّل الدخول بحساب GitHub نفسه.
2. من زر **New** اختر **Blueprint**.
3. اسمح لـ Render بالوصول إلى المستودع `molook-al-tarneeb` (يكفي هذا المستودع وحده).
4. سيقرأ `render.yaml` ويعرض خدمة باسم `molook-al-tarneeb` بخطة **Free**. اضغط **Apply** (أو Deploy Blueprint).
5. انتظر بضع دقائق حتى تصير الحالة **Live**. رابط الموقع يظهر أعلى صفحة الخدمة بالشكل `https://molook-al-tarneeb.onrender.com` (قد تضيف Render لاحقة إن كان الاسم مأخوذًا).

### 3) جرّب

1. افتح الرابط: تظهر صفحة الأسطورة.
2. اضغط «ابدأ اللعب الآن»، أنشئ غرفة، وافتح رابط الدعوة من ثلاثة أجهزة أخرى (هواتف مثلًا).

## ما يجب معرفته عن الخطة المجانية

مصدر هذه المعلومات صفحات Render الرسمية وقت كتابة هذا الملف، وقد تتغير:

- **تنام الخدمة بعد 15 دقيقة** بلا أي طلب أو رسالة WebSocket. أول زائر بعد النوم ينتظر نحو دقيقة حتى تستيقظ. أثناء وجود صفحة اللعبة مفتوحة يرسل المتصفح نبضة كل 15 ثانية، وبحسب وثائق Render تُحسب رسائل WebSocket نشاطًا، فيُفترض أن تبقى الخدمة مستيقظة (لم يُجرَّب هذا فعليًا على Render).
- **لا قرص دائم**: عند النوم أو إعادة النشر تضيع الغرف الجارية. رمز الغرفة القديم لا يعمل بعدها، وتُنشأ غرفة جديدة.
- **بعد دفع تحديث إلى GitHub** يفترض أن تنشر Render تلقائيًا؛ إن لم يحدث فافتح الخدمة واختر **Manual Deploy ← Deploy latest commit**.
- **750 ساعة تشغيل شهريًا** للحساب كله؛ إن انتهت توقفت الخدمات المجانية حتى الشهر التالي.
- الخطة المجانية تناسب لعب الأصدقاء والتجربة، لا حملًا كبيرًا.

## إن لم يتصل اللعب

إن ظهرت صفحة الأسطورة لكن اللعبة تقول إنها لا تستطيع الاتصال بالخادم:

1. في Render افتح الخدمة ثم **Environment**.
2. أضف متغيرًا اسمه `ALLOWED_ORIGINS` وقيمته رابط موقعك كاملًا، مثل `https://molook-al-tarneeb.onrender.com` (بلا شرطة مائلة في آخره).
3. احفظ، وانتظر إعادة التشغيل التلقائية.

## تحديث الموقع لاحقًا

عند تعديل المشروع شغّل `npm run deploy:bundle` في المشروع الأصلي (يتطلب Node 22)، وارفع محتويات المجلد الناتج `deploy-bundle/` فوق المستودع. تعيد Render النشر تلقائيًا.

## اللعب الفردي وتنام الخدمة

«العب وحدك» يعمل كله في المتصفح ولا يحتاج الخادم. وبعد أن تفتح الموقع مرة واحدة وهو متصل يُحفظ على جهازك، فإن كانت الخدمة المجانية نائمة (أو لا يوجد إنترنت) يُفتح اللعب الفردي من النسخة المحفوظة بعد ثوانٍ قليلة بدل انتظار الاستيقاظ. أما اللعب مع الأصدقاء أونلاين فيحتاج الخدمة مستيقظة.

## حدود هذا الدليل

نُشر الموقع فعليًا على Render بهذه الخطوات بمساعدة صاحبه عبر الهاتف، وأكّد أن الحالة **Live**. لم أفتح الرابط العام من بيئة التطوير. لم يُشغَّل `Dockerfile` بـ Docker في بيئة التطوير، وجُرّب تشغيل الخادم المبني بـ Node مباشرة بالإعدادات نفسها.
